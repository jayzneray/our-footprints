# 我们的足迹

嘉怡和政兴的旅行日志。静态网站，部署在 GitHub Pages。

- 地球：globe.gl（MIT）
- 国家轮廓：Natural Earth（公有领域）；中国省界：ECharts 4.9.0 china.json（Apache 2.0）

要修改这个网站：可编辑源码在 `src/`，不要手改根目录 `index.html`。请先阅读 [AGENTS.md](AGENTS.md) 和 [HANDOFF.md](HANDOFF.md)。在仓库根目录运行 `python3 build.py` 生成页面；本地预览用 `node tools/serve.js`（这是 Node 脚本）。
